🎯 Обзор

Gotcha — это программа для тестирования устойчивости сетевых устройств и протоколов в контролируемых лабораторных условиях. Она позволяет:

    Генерировать различные типы сетевого трафика

    Имитировать сетевые атаки (DHCP starvation, ARP spoofing, DoS и др.)

    Перехватывать и анализировать пакеты

    🔗 Поддержка платформ
    • Windows (текущая версия) - Полная поддержка
    • Linux - Доступен форк сообщества: Gotcha-linux

🛠️ Типы атак

    DHCP Starvation - Истощение пула DHCP-адресов

    ARP Spoofing - Подмена ARP-таблиц

    DoS/DDoS - Отказ в обслуживании

    Генерация кастомных пакетов

📦 Обязательное ПО

    Npcap - Драйвер для захвата и генерации пакетов

        ВАЖНО: При установке выберите опцию WinPcap API-compatible Mode

    Microsoft Visual C++ Redistributable - Последняя версия

🛠️ Рекомендуемое ПО

    Wireshark - Для анализа трафика и отладки

    Nmap - Для поиска уязвимостей

    TCP Optimizer - Для оптимизации сетевой карты (увеличивает количество создаваемых пакетов для DoS-атак)

🔧 Установка
Способ 1: Установщик 

    Скачайте последнюю версию установщика из Releases

    Запустите установщик с правами администратора

    Следуйте инструкциям мастера установки

    Запустите программу через меню "Пуск"


🚀 Быстрый старт
Подготовка к работе

    Установите Npcap с включенным режимом совместимости с WinPcap

    Установите Gotcha через инсталлятор

    Запустите программу от имени администратора

    Ознакомьтесь с руководством пользователя (guide.html)
